# Before You Submit

- [ ] Open `index.html` and check the page on desktop and mobile.
- [ ] Read `FIGMA_BUILD_GUIDE.md`.
- [ ] Create a Figma file with desktop and mobile frames.
- [ ] Add the color and typography styles listed in the guide.
- [ ] Create at least 3 reusable components and apply Auto Layout.
- [ ] Add your name/student details if required.
- [ ] Upload the website files to GitHub.
- [ ] Add the GitHub repository link to the Google Sheet.
- [ ] Share the Figma file link if your instructor requests it.

**Note:** The ZIP cannot publish to your accounts or create a native Figma file automatically. Those final account actions must be completed by you.
