# SkillNest Figma starter kit

This kit includes the SkillNest website files from the original project (where available), an SVG vector reference to import into Figma, design tokens, and a practical guide for building native Figma Auto Layout frames, reusable components, and shared colour/text styles.

**Important:** SVG import does not create native Figma Auto Layout, components, or styles. Follow `FIGMA_AUTOLAYOUT_COMPONENTS_STYLES_GUIDE.md` in Figma to create these features before submitting the assignment.

Recommended order:
1. Import `SkillNest_Figma_Starter.svg` as a visual reference.
2. Rebuild sections with native Figma frames and Auto Layout.
3. Create the shared colour and text styles.
4. Create `Button / Primary`, `Navigation / Link`, and `Card / Feature` components.
5. Create a 390 px mobile frame and adapt the layout.
